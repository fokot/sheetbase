02 / QUICK START

One table.
A clear API.

Connection, schema, and writes. No exercise names
or habit rules built into the core.

import {
  createSheetbase, createIndexedDBStorage,
  createGoogleSheetsRemote, column
} from '@fokot/sheetbase';

const db = createSheetbase({
  accountId: googleUser.id,
  storage: createIndexedDBStorage('my-app'),
  remote: createGoogleSheetsRemote({
    getCredentials: () => ({
      accountId: googleUser.id,
      accessToken: tokenInMemory
    })
  })
});

const journal = db.table({
  spreadsheetId: sheetId,
  sheet: 'Journal',
  keyColumn: 'Date',
  columns: {
    walk: column.boolean('Walk'),
    pages: column.number('Pages')
  }
});

await journal.open({ create: true });
await journal.set('2026-10-27', { walk: true });
A.

Access through your account

Your app supplies a verified account and an in-memory token. The library never opens sign-in windows or stores the token.

B.

Typed columns

Text, numbers, booleans, JSON, or your own format. null clears a cell; 0 and false are values.

C.

You own the schema

The key lives in column A. You can keep other columns outside the schema; writes preserve them.

05 / KNOW THE LIMITS

A small backend.
Honest about limits.

Version 0.1 is a working prototype for evaluating the API.

NOT CONNECTED TO THE TRACKER

Personal applications

A starting point for journals, trackers, and internal tools. Access follows Google account and file permissions.

Manual sheet edits

Positions are reread before writing. A renamed managed column or duplicate key stops synchronization; concurrent sorting can still cause a conflict.

Concurrent devices

The last successful cell write wins. The library offers neither distributed transactions nor row-level security rules.

Schema and sign-in

Automatic schema migrations and OAuth screens are not included. The existing tracker stays unchanged and its data is not imported.

↳

The Google adapter is tested against a simulated API, not your sheets. Sync runs while the app is open; page caching belongs to the app. IndexedDB coordinates browser tabs with Web Locks.
